# features

テストを要約した機能一覧。`storymap.md`より細かい粒度で、アプリの振る舞いを階層のリストで示す。

- 起動
  - 起動時に設定ファイルがない場合、ライブラリ管理ウィンドウの上にモーダルの設定ウィンドウを表示
  - 起動時に設定ファイルがある場合、設定ウィンドウは開かず、ライブラリフォルダの走査結果を一覧に表示
  - 設定の保存先はユーザホームの.sss-music-player/settings.properties（システムプロパティsss.settings.fileで変更可能）
  - 設定ウィンドウでフォルダを選択すると、音楽ライブラリのパスを設定ファイルに保存。選択をキャンセルした場合は変更なし
  - 設定の保存に失敗すると、エラーダイアログを表示し、アプリは続行
  - 起動時に設定ファイルが読めない場合、エラーダイアログを表示し、初期設定で起動（設定ウィンドウを開き、次の保存で上書き）
  - 設定ファイルのテーマ名・リピートモード名・音楽ライブラリのパスが不正な場合も、読めない場合と同じ扱い（RepositoryExceptionとして報告）
- ライブラリスキャン
  - ライブラリスキャンは、指定フォルダとサブフォルダのmp3・m4aファイルを一覧化。拡張子の大文字小文字は区別せず、ドット始まりの隠しファイルはスキップ
  - スキャン時にタグ（曲名・アーティスト・アルバム・アルバムアーティスト・トラック番号・年）を読み込み。タグが無い・読めないファイルは空タグのままライブラリに保持
  - スキャンはバックグラウンドで実行し、完了時に一覧を更新
  - スキャン中はモーダルのScanningダイアログに読み込み中のファイルパスを表示し、完了すると閉じる
  - メタデータのキャッシュ先はSQLiteのライブラリDB（ユーザホームの.sss-music-player/library.db、システムプロパティsss.library.dbで変更可能）
  - キャッシュは、パスとサイズが同じで、ファイル側の更新日時がDB側以前ならヒット。ミス時はファイルから読み直してDBを上書き
  - スキャンはDBを消さない差分更新。スキャン後、ファイルシステムに存在しないエントリをDBから削除
  - FileメニューのRescanでライブラリを再スキャン
  - アルバム認識は、アルバム名とアルバムアーティストの一致で1アルバムに集約。アルバム名が空のファイルは親フォルダごとに1アルバム
  - アルバム一覧は、1行につき1アルバムを「アルバム名 - アルバムアーティスト」で表示
  - アルバム一覧のソートキーはComboBoxで切替（Album／Artist、初期値Album）。大文字小文字を無視した昇順で表示
  - 絞り込みフィールドでアルバム一覧をインクリメンタルに絞り込み（アルバム名・アルバムアーティスト名の部分一致、大文字小文字無視）。右端のxボタンでクリア
  - アルバムを選択すると、曲リストに「トラック番号. 曲名」をトラック番号順で表示し、最初の曲を選択済みにする
  - 曲名が空の曲は、曲リストにファイル名で表示
- 重複検出・除去
  - 重複検出は3方式：ファイル名とサイズの一致／ファイル名の一致／メタデータ（曲名とアーティスト）の一致
  - メタデータによる重複判定では、曲名またはアーティストが空のファイルは除外。アルバムが異なるファイルは別グループ
  - 重複グループ内のファイルはサイズの大きい順（同サイズは発見順）
  - FileメニューのRemove duplicate files...で、重複リストウィンドウ（Duplicate Files）を開く
  - 重複グループを選択すると、右の固定幅パネルに各ファイルのパス・サイズ（MBとバイト数）・再生ボタン・Open Folderボタンを表示
  - 重複確認パネルの再生ボタンでファイルを試聴（ボタンは▶／■で切替）
  - 重複除去は、チェックしたグループの最初の1つ以外をduplicatesフォルダへ移動。同名ファイルは連番付きにリネームし、日付・移動元・移動先をログに記録
  - Toggle allで全グループのチェックを一括切替。チェックが1つもないときRemoveボタンは無効
  - 重複除去の実行後は、ライブラリを再スキャン
  - ライブラリのファイル一覧が変わると、最後の判定条件で重複候補リストを自動更新
- メタデータ編集
  - アルバム情報パネルのEditボタンで、メタデータ編集ウィンドウ（Edit Album）を開く。アルバム未選択のときEditボタンは無効
  - 編集ウィンドウでは、選択中のアルバムのアルバム名とアルバムアーティストを編集できる
  - アルバムアーティストが空の場合、最初の曲のアーティスト名を自動入力
  - アルバムの元の値と異なる値のフィールドは、背景が明るい黄色になる。Saveすると基準が保存値に移り、黄色は消える
  - アルバム名かアルバムアーティストが変更されている場合のみ、Saveボタンが有効
  - Saveすると、アルバムの全トラックのタグにアルバム名とアルバムアーティストを書き込み
  - Save後は、Saveボタンの下に「編集ウィンドウを閉じるとライブラリが再読み込みされます」を表示（ウィンドウを開き直すと消える）
  - 編集ウィンドウを閉じると、そのセッションで保存があった場合のみライブラリを再スキャン
- プレイヤー
  - 再生ボタンで選択中の曲を再生。再生中はボタン表示が一時停止（❘❘）に切替
  - 一時停止後の再生は続きから再開。一時停止中に別の曲へ移動して再生した場合は冒頭から再生
  - 停止ボタンで再生を停止
  - 再生中に別の曲をダブルクリックすると、その曲の再生を開始
  - 次の曲（▶▶）・前の曲（◀◀）ボタンで曲リストの選択を移動（先頭・末尾はラップ）。再生中は移動先を即再生
  - 全曲リピートでは、1曲の再生が終わると次の曲を自動再生（末尾の曲では先頭へ）
  - プレイヤーパネルのOpen folderボタンで、選択中の曲のフォルダを開く（未選択時は何もしない）
  - 停止ボタンの右のリピートボタンでリピートモードをトグル（全曲リピート／1曲リピートの2種、初期値は全曲リピート）。表示はrepeat all／repeat one
  - 1曲リピートでは、1曲の再生が終わると同じ曲を先頭から再再生
  - 再生中は、アルバムの切替などで曲リストの選択が解除されても、再生中の曲を選択したままにする（1曲リピートの再再生も再生中の曲が対象）
  - リピートモードは変更のたびに設定ファイルに保存し、起動時に再現（記載が無い場合は全曲リピート）
- 設定
  - 設定ウィンドウのプルダウンでテーマを切替（Primer Light／Primer Dark／Nord Light／Nord Dark／Cupertino Light／Cupertino Dark／Draculaの7種、初期値は現在のテーマ）
  - 選んだテーマは即時反映し、設定ファイルに保存（ライブラリパス未設定のときは反映のみで保存しない）
  - 起動時は設定ファイルのテーマを適用（テーマの記載が無い場合はPrimer Light）
  - テーマだけの変更ではライブラリを再スキャンしない
