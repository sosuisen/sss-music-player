    - [x] プルダウンの初期値は現在のテーマ。
    - [x] 選んだテーマを保存。
      - [x] Settingsのテーマを保存・読み込みできる（保存形式はtheme=enum名）。
      - [x] 設定ファイルにテーマが無い場合はPrimer Light。

      - [x] ライブラリパス未設定のときはテーマを保存しない（即時反映のみ）。
    - [x] 起動時に保存済みテーマが適用される。
    - [x] フォルダ選択時も現在のテーマが維持される。
    - [x] テーマを変えたときにrescanが走らない。
    - [x] 選んだテーマを即時反映。
