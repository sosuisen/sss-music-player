# sss-music-player

2026/10/21

PC上に散らばった古い音楽ファイルを整理するアプリ。

日常的にシンプルに音楽の聴けるプレイヤーも欲しい。整理アプリと機能的に共通部分が多く、利用する場面も同じであるため、プレイヤー機能も追加した。

主なユーザーは開発者自身。長年にわたるCDからのリッピングや、複数のサービスからの購入で大量の音楽ファイルを蓄積してきたコレクター。古いツールで作られたShift_JISの日本語タグを持つファイルも保有。日常的にPCで音楽を聴く。


1. アクティビティ
2. タスク
3. ウォーキングスケルトン
4. メタデータの編集・利用
5. プレイ体験向上

- 準備する
  - 音楽ファイルを集める
    - [x] 全ての音楽フォルダーを、1つの指定フォルダー以下に置く
  - プレイヤーを開く
    - [x] 指定フォルダーがなければ指定する
      - vv スキャン先フォルダーを追加する
    - [x] 指定フォルダー内のmp3、m4aファイルをスキャンする
      - [x] スキャンしたファイルをキャッシュする
  - テーマ変更
    - [x] ライト・ダークテーマの変更
- アーカイブの整理
  - 重複ファイルの検出
    - [x] ファイル名とサイズの一致検出
      - [x] メタデータの一致検出
  - 検出ファイルの試聴
    - [x] 再生ボタン追加
  - 検出ファイルの後処理
    - [x] ファイルをフォルダーから除去
      - [x] ^ ファイルのあるフォルダーを開く
  - メタデータを修正する
    - [x] v アルバム名とアルバムアーティストの編集
      - [x] ^ アルバムアーティストに曲のアーティスト名を自動入力
        - [x] ^ 曲のメタデータ編集
- 音楽を楽しむ
  - アルバムを選ぶ
    - [x] v リストから探す
      - [x] ^ 検索窓から探す
  - 再生・停止する
    - [x] v 再生・停止ボタン
      - [x] ^ 早送り、巻き戻し、一時停止
        - [x] ^ 一曲リピート、アルバムリピートのトグル
          - [ ] プレイリストから再生
            - ^ アルバム名ダブルクリックで先頭曲から再生
  - 再生中のアルバムを整理する
    - [x] v メタデータを修正する
      - [x] ^ アルバムのフォルダーを開く
      - [ ] プレイリスト登録
