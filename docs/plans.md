TDDの作業用todoリスト（使い捨て）。

## 再生機能

- [x] ライブラリウィンドウを上下に分けて、下は横長のプレイヤーパネルにする。
  - [x] プレイヤーパネルに、再生ボタン（▶）と停止ボタン（■）が表示される。
  - 決定: 固定高さの下部パネル（縦SplitPaneではない）。
- [x] 再生ボタンで再生、停止ボタンで停止。
  - [x] 再生ボタンを押すと、曲リストで選択中の曲の再生がプレイヤーに要求される。
  - [x] 停止ボタンを押すと、プレイヤーに停止が要求される。
- [x] 再生ボタンを押すと、一時停止アイコン（❘❘）に切り替わる。
- [x] 一時停止ボタン（❘❘）を押すと、再生が一時停止する（▶で続きから再開）。
- [x] 1曲再生が終わったら次の曲へ。末尾の曲では先頭へ戻る。
  - [x] 1曲の再生が終わると、次の曲が再生される（末尾の曲では先頭へ戻る）。
  - 決定: MusicPlayerにsetOnFinished(Runnable)を追加し、ViewModelが終了時にnextTrack相当を呼ぶ。
- [x] 次の曲へ、前の曲へボタン。
  - [x] 次の曲ボタン（▶▶）を押すと、曲リストの選択が次の曲に移る。
  - [x] 前の曲ボタン（◀◀）を押すと、曲リストの選択が前の曲に移る。
  - [x] 末尾で▶▶は先頭へ、先頭で◀◀は末尾へラップする。
  - [x] 再生中に▶▶/◀◀を押すと、移動先の曲が即再生される。
  - 決定: 非再生時は選択だけ移動。
- [ ] 曲がダブルクリックされると、現在の再生を停止して、ダブルクリックされた曲の再生開始。
- [ ] 1曲リピート再生。
- [x] 一時停止状態で別の曲へ移動した場合、resume時には現在選択されている曲の冒頭から再生する。
- 決定: 再生対象は曲リストで選択中の曲。未選択なら何もしない。
