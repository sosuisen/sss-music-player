# plans

TDDの作業用todoリスト（使い捨て）。

## 再生機能

- [ ] 1曲リピート再生。

## ライブラリマネージャー

- [ ] お気に入りへ追加機能。
- [ ] 入力フィールドでアルバムの絞り込み。
- [ ] アルバム名、アーティスト名、曲名の文字化けを修正。
  - 原因: ID3v2.3の宣言はLatin-1だが中身はShift_JISのタグ。
  - 方針A: 読み込み時にLatin-1でバイト列に戻しMS932で読み直すヒューリスティック。ファイルは書き換えない。
  - テストリスト:
    - [ ] Latin1で読み込んだ文字列の文字化けの検出
      - [x] 三角測量: 文字化けしていない文字列はfalse（ASCIIのみ）
      - [x] 三角測量: Caféのような正しいLatin-1西欧文字列は、誤復号と判定されない
    - [ ] mp3かつエンコーディング宣言00（ISO-8859-1）のときのみ文字化け修正を実行する
