## 重複候補の一覧表示

- [ ] 重複判定関数
  - [x] ファイル名とサイズに基づく判定
    - [x] ファイル名が同じかつサイズが同じものを重複判定。
    - [x] Find by Filename and Sizeボタンを押したら、判定実行。
  - [ ] ID3タグの曲名、アーティストに基づく判定
- [x] 重複リストウィンドウの左側に重複候補リスト、右側に重複確認パネルを置く。
- [x] 重複候補リストの項目を選択すると、右の重複確認パネルに内容が表示される。
- [x] 重複確認パネルには、選択したグループの重複ファイルたちをリストに並べ、行ごとにファイルパス、サイズ、再生ボタンを置く。
- [x] 再生ボタンを押したら、音楽を再生。
- [x] 再生ボタンを押したら、停止ボタンにアイコン変更。
- [x] 停止ボタンを押したら、音楽を停止。
- [x] 重複リストの左端にチェックボックス追加。
- [x] detectを呼ぶと、チェック状態はすべてクリアされる。
- [x] ライブラリのファイル一覧が変わると、最後の判定条件で候補リストが更新される。
- [x] チェックが1つもないときは、重複を除去ボタンが押されないようにする。
- [x] 候補リスト下段で「Remove checked duplicates」の左隣に「Toggle all」を置く。
- [x] Toggle allボタン: 1つでもチェックされていたら全解除、1つもチェックされていなければ全選択。
- [x] 検索ボタンを重複候補リストの上側へ。
- [x] 候補リストの下行の右端に、重複を除去ボタンを追加。
- [x] 重複を除去ボタンを押すと、重複のうち最初の1つ以外のファイルは、ユーザホームのこのアプリのセッティングフォルダの下のduplicatesサブフォルダへ移動。
  - [x] チェックされたグループだけが対象。移動処理はservice層。
  - [x] duplicates/に同名ファイルがある場合は、移動先のファイル名を変える。
  - [x] 移動ログを~/.sss-music-player/duplicates.logに記述（日付,移動元ファイルパス,移動先ファイル名）。
  - [x] 移動後は再スキャン。
