# plans

TDDの作業用todoリスト（使い捨て）。

## 重複候補の一覧表示

- [x] メタデータ重複判定は、曲名・アーティスト名に加えてアルバム名も一致するべき。
  - [x] 曲名とアーティストが同じでも、アルバムが異なるファイルは同じグループにならない。
  - アルバム名が空のファイルは判定に含める（除外は曲名・アーティストが空の場合のみ）。

## アルバム認識機能

- [ ] ID3によるアルバム認識。
  - [ ] ライブラリマネージャーのリストは、1行につき1アルバム。
    - [x] アルバム名とアルバムアーティストが同じファイルが、1つのアルバムにまとまる。
    - [x] アルバム名が空のファイルは、同じ親フォルダごとに1つのアルバムになる（フォルダによるアルバム認識へのフォールバック）。
    - [x] ライブラリ一覧は、1行につき1アルバムを「アルバム名 - アルバムアーティスト」で表示する。
    - [x] 親フォルダが無いファイルは、空の名前のアルバムになる（NPEガード）。
    - 決定: キーはアルバム名＋アルバムアーティスト。表示は「アルバム名 - アルバムアーティスト」。
    - 決定: アルバム名が空のファイルはフォルダで認識。親フォルダのパス単位、name=フォルダ名、artist=空。
- [ ] フォルダによるアルバム認識。
