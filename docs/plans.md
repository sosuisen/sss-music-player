# plans

TDDの作業用todoリスト（使い捨て）。

## 再生機能

- [ ] 1曲リピート再生。
- [x] プレイヤーの右端に「Open folder」ボタン追加。
- [x] Open Folderが押されると、この曲のフォルダが開く。
  - [x] 未選択なら何もしない。
- 決定: 再生対象は曲リストで選択中の曲。未選択なら何もしない。

## ライブラリマネージャー

- [ ] お気に入りへ追加機能。
- [ ] 入力フィールドでアルバムの絞り込み。
- [x] ファイルスキャンで、先頭が.で始まる隠しファイルはスキップする。
- [ ] scanning中は、DuplicateListViewで重複削除できないようにする。

## その他

- [ ] アプリ起動時のエラー処理。
