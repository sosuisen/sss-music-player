# plans

TDDの作業用todoリスト（使い捨て）。

## 再生機能

- [ ] 1曲リピート再生。

## ライブラリマネージャー

- [ ] お気に入りへ追加機能。
- [ ] 入力フィールドでアルバムの絞り込み。
- [ ] 曲リストの行に、曲名の後ろに（アーティスト名）を表示。
- [x] Albumモデルは年情報も持つ。
- [x] yearをアルバム情報パネルに追加。
- [ ] アルバム情報パネルにEditボタンを追加。押すとメタデータ編集ウィンドウが開き、アルバムのメタデータを編集・保存できる。
  - 編集フィールド: アルバム名・アルバムアーティスト（アルバムの全トラックに一括適用）。年は編集対象外。
  - 保存先: 音声ファイルのタグ（保存後に再スキャンで一覧へ反映）。
  - レイアウト: 編集ウィンドウはGridPane（SettingsViewと同様）。
  - テストリスト:
    - [x] アルバム情報パネルにEditボタンが表示され、押すとメタデータ編集ウィンドウが開く。
    - [x] アルバム未選択のとき、Editボタンは無効。
    - [x] タグ書き込み: mp3のタグにアルバム名・アルバムアーティスト・年を書き込める。
    - [x] タグ書き込み: m4aにも同様に書き込める。
    - [x] 編集ウィンドウに、選択中のアルバムのアルバム名・アルバムアーティストが初期表示される。
    - [ ] Saveすると、アルバムの全トラックのタグに編集内容が書き込まれる。
    - [ ] Saveすると、変更プロパティ（albumNameChanged・albumArtistChanged）はすべてfalseになる。
    - [x] Saveすると、ライブラリ変更フラグが立つ。
    - [x] 編集ウィンドウを開いたときには、ライブラリ変更フラグを落とす。
    - [x] ライブラリ変更フラグが立っているときのみ、編集ウィンドウを閉じるとライブラリが再スキャンされる。
    - [ ] ライブラリ変更フラグが立っている間のみ、Saveボタンの下に「編集ウィンドウを閉じるとライブラリが再読み込みされます」と表示される。
    - [x] アーティスト名かアルバム名のどちらかが変更されている場合のみ、Saveボタンが有効。
    - [x] アルバムの元の値と異なる値が入力されているフィールドは、背景が明るい黄色になる。
    - [x] 開いた後、アルバムアーティストが空の場合、最初の曲のアーティスト名を自動入力する（背景は明るい黄色になる）。
