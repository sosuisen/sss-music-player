# plans

TDDの作業用todoリスト（使い捨て）。

## 再生機能

- [x] 曲がダブルクリックされると、現在の再生を停止して、ダブルクリックされた曲の再生開始。
  - [x] 再生中に別の曲をダブルクリックすると、その曲の再生が開始される。
- [ ] 1曲リピート再生。
- 決定: 再生対象は曲リストで選択中の曲。未選択なら何もしない。

## ライブラリマネージャー

- [x] Rescanでlibrary.dbを全て消して再スキャン。
  - [x] rescanメソッドは、library.dbを消してscanを実行する。
- [ ] SqliteLibraryDatabase.deleteAllの単体テスト。
- [x] アルバム名でソート。
  - [x] ソートキーのComboBox（初期値Album）が表示され、アルバムリストはアルバム名の昇順（大文字小文字無視）で並ぶ。
  - 決定: ComboBoxで切替。昇順・大文字小文字無視。
- [x] アーティスト名でソート。
  - [x] コンボボックスにArtist追加。
  - [x] コンボボックスが変更されると、選択されたキーでソート。
- [ ] お気に入りへ追加機能。
- [x] アルバムを選択すると、曲リストの最初の曲が選択済みとなる。
