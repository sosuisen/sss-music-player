# plans

TDDの作業用todoリスト（使い捨て）。

## 再生機能

- [ ] ライブラリウィンドウを上下に分けて、下は横長のプレイヤーパネルにする。
  - [x] プレイヤーパネルに、再生ボタン（▶）と停止ボタン（■）が表示される。
  - 決定: 固定高さの下部パネル（縦SplitPaneではない）。
- [ ] 再生ボタンで再生、停止ボタンで停止。
  - [x] 再生ボタンを押すと、曲リストで選択中の曲の再生がプレイヤーに要求される。
  - [x] 停止ボタンを押すと、プレイヤーに停止が要求される。
- [ ] 再生ボタンを押すと、一時停止アイコン（❘❘）に切り替わる。
- [ ] 一時停止ボタン（❘❘）を押すと、再生が一時停止する（▶で続きから再開）。
- [ ] 1曲再生が終わったら次の曲へ。末尾の曲では先頭へ戻る。
- [ ] 次の曲へ、前の曲へボタン。
- 決定: 再生対象は曲リストで選択中の曲。未選択なら何もしない。
